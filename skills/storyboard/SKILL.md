# Storyboard —— 剧本转分镜

## 用途

把一段剧本（短片、动画、广告、短视频脚本）转换成结构化的分镜清单，供后续出图、剪辑或人工拍摄参考。

## 输入格式

输入是一份剧本，可以是以下任意一种：

- 纯文本剧本（带场景标题，如 `场景 1：清晨的厨房`）
- Markdown 剧本（用 `#` / `##` 分场景）
- 对话体剧本（角色名 + 台词 + 动作提示）

输入中至少要包含：场景数量（或能推断出的场景边界）和每场的大致内容。
如果剧本没有显式的场景划分，先按地点 / 时间变化切分，并在输出中注明切分依据。

## 流程

### 1. 读剧本

通读全文，记录：总场景数、每场的时间、地点、出场角色、核心冲突 / 情绪转折。

### 2. 拆场景

按以下规则切分场景：

- 地点变化 → 新场景
- 时间跳跃（如“三年后”“当晚”）→ 新场景
- 同一地点但叙事段落明显断开 → 可拆为两个场景，并在备注中说明

每个场景编号为 `S01、S02……`，并给出一句场景梗概（不超过 30 字）。

### 3. 每场输出 1 张分镜描述

每场只出 1 张分镜（除非剧本明确要求一场多镜），包含以下字段：

| 字段 | 说明 |
| --- | --- |
| 场景编号 | 如 S01 |
| 景别 | 全景 / 中景 / 近景 / 特写 / 大特写 / 远景，六选一 |
| 机位 | 如：正面平拍 / 侧面低机位 / 俯拍 / 过肩镜头，并注明是否运动（固定 / 推 / 拉 / 跟） |
| 画面内容 | 画面里有什么：人物位置、动作、环境元素，不超过 80 字 |
| 动作 | 角色在这一镜里的关键动作 |
| 台词 | 该镜对应的台词原文；无台词写“无台词” |
| 时长建议 | 建议秒数，如 3–5 秒 |
| 转场 | 与下一镜的衔接方式：直切 / 淡入淡出 / 叠化 / 跳切；最后一场写“结束” |

### 4. 输出分镜清单

按场景顺序汇总成一张 Markdown 表格 + 每场一段文字描述。
表格列：场景 | 景别 | 机位 | 动作 | 台词 | 时长。
表格之后附“备注”一节：写清剧本中模糊、缺失的信息（如未写明地点、角色人数不明），以及你是如何处理的。

## 输出示例

```markdown
## 分镜清单

| 场景 | 景别 | 机位 | 动作 | 台词 | 时长 |
| --- | --- | --- | --- | --- | --- |
| S01 清晨的厨房 | 中景 | 正面平拍，固定 | 母亲把粥端上桌 | “快吃，要凉了。” | 4 秒 |

### S01 详细描述
……
```

## 约束

- **不编造不存在的镜头**：只转化剧本里已有的场景、角色、台词和动作；剧本没写的地点、角色、道具、台词一律不自行添加。如需补全，必须写在“备注”里并标明是“推测 / 待确认”。
- **不承诺图片 / 视频生成能力**：本 skill 只输出分镜文字描述，不生成图片、不生成视频、不调用任何生图 / 生视频模型。如需出图，交给 `image-prompt` skill 先写提示词，再由用户自行调用生图工具。
- **一场一镜**：除非剧本明确要求，否则每场只出 1 张分镜，不自行扩写多镜。
- **台词逐字引用**：台词必须照抄剧本原文，不改写、不润色、不续写。
- **数量上限**：单次处理不超过 30 场；超过时先输出前 30 场并提示剩余场次需分批处理。
- **不确定的地方要明说**：场景边界、角色、时间线有歧义时，在备注中列出，不猜测后悄悄定案。
