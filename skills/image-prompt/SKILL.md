# Image Prompt —— 图片提示词

## 用途

把用户的中文图片需求（或一段分镜描述）转换成可直接粘贴到生图工具里的提示词：中英双语正向提示词 + 负面提示词。

## 输入格式

输入可以是以下任意一种：

- 一句话需求，如“画一张赛博朋克风格的夜市”
- 一段分镜描述（如 storyboard skill 输出的某场画面内容）
- 一组零散要求：主体 + 风格 + 氛围，缺项也没关系，缺失项会在输出中标注

## 流程

### 1. 读需求

提取用户明确给出的信息，区分“已给出”和“未给出”两类；未给出的项不擅自脑补成事实，只在提示词里用通用表述或留空待填。

### 2. 拆解为四个维度

| 维度 | 包含内容 |
| --- | --- |
| 主体 | 画面中心是什么：人物 / 物体 / 场景，数量、姿态、服装、关键特征 |
| 风格 | 画风：写实摄影 / 电影感 / 水彩 / 扁平插画 / 赛博朋克 / 吉卜力风等；注明媒介（照片 / 插画 / 3D 渲染） |
| 光线 | 光源方向与质感：清晨柔光 / 午后硬光 / 霓虹夜光 / 逆光剪影；色温倾向（暖 / 冷） |
| 构图 | 景别（全景 / 中景 / 特写）、视角（平视 / 俯视 / 仰视）、画面比例建议（如 16:9、3:2、1:1）、主体位置（居中 / 三分法） |

### 3. 输出中英双语提示词 + 负面提示词

输出结构固定如下：

```markdown
## 正向提示词（中文）
……

## Positive Prompt（English）
……

## 负面提示词（中文）
……

## Negative Prompt（English）
……

## 备注
- 未确认项：……
- 建议比例：……
```

英文提示词用逗号分隔的短语串，不写完整长句；中英文内容必须一一对应，不可一边多出另一边没有的要素。
负面提示词默认包含：模糊、低质量、多余肢体、文字水印、过曝、变形；用户有额外排除项时追加。

## 输出示例

```markdown
## 正向提示词（中文）
雨夜的赛博朋克夜市，霓虹招牌倒映在湿漉漉的地面上，一个撑着透明伞的行人走过小吃摊，电影感，16:9

## Positive Prompt（English）
cyberpunk night market in the rain, neon signs reflecting on wet pavement, a pedestrian with a transparent umbrella walking past food stalls, cinematic, 16:9

## 负面提示词（中文）
模糊，低质量，多余肢体，文字水印，过曝，变形

## Negative Prompt（English）
blurry, low quality, extra limbs, text watermark, overexposed, deformed
```

## 约束

- **只出提示词文本，不直接生成图片**：本 skill 的产出就是提示词本身，不调用任何生图模型、不返回图片文件。用户拿到提示词后自行去生图工具里使用。
- **不编造模型能力**：不承诺某个模型“一定能画出”某效果，不写“用 XX 模型可出图”之类的保证；不同生图工具对同一提示词的效果不同，这一点要在备注里说明。
- **不擅自补全未给出的关键信息**：主体、风格等核心项用户没给时，提示词里用通用表述，并在“备注-未确认项”中列出，请用户补一句即可细化；不把猜测写成定稿。
- **中英严格对应**：英文提示词不得加入中文版没有的内容，反之亦然。
- **不输出违规内容**：不写涉及未成年人、真实人物肖像伪造、暴力血腥细节的提示词；遇到这类需求直接拒绝该部分并说明原因。
- **一次只做一张图**：一个需求对应一张图的提示词；多图需求请分条提交。
